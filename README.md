# Tarefas-em-C-Manipulcao-de-Variaveis
Tarefas utilizando C no curso técnico de informática do Instituto Federal Catarinense campus São Bento do Sul, realizado em 18 de ago. de 2025

Atividades:

Implemente os programas a seguir em C:

1 - Solicite uma entrada de dados para ler e armazenar um número inteiro em uma variável. Logo após, utiliza a saída de dados para
exibir o número digitado.

2 - Solicite uma entrada de dados para obter e armazenar o nome do usuário em um variável. Logo após, utiliza a saída de dados para exibir o nome digitado.

3 - Receba três números inteiros do usuário.  Em seguida, mostre os números na ordem inversa em que foram digitados.

4 - Solicite ao usuário que informe seu nome e sua idade. Em seguida, mostre na saída a mensagem "Olá <nome>, você tem <idade> anos". Onde <nome> e <idade> devem ser substituídos pelas variáveis lidas.
